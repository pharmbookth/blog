Welcom! In this post, I want to share my journey of learning Vim and how I used it to build this tiny website from scratch.

I originally started coding with VS Code, which is a fantastic editor that most programmers love. However, during a family vacation in Krabi, Thailand, I was lying lazily in bed scrolling throgh Reddit when I stumbled upon a discussion about Vim.

Curious, I didn't hesitate to give it a try. It was love at first sight! Vim is incredibly fast, comfortable, and most importantly, allows you to navigate completely mouse-free.

Quick Vim Command I Used to Build This Site

For anyone curious about getting started with Vim, here are a few essential commands that helped me edit this page:

  • i - Enter Insert Mode to start typong text.
  • Esc - Return to Normal Mode.
  • h / j / k /l - Move the cursor Left, Down, Up, and Right without using arrow keys.
  • dd - Delete (cut) the current line.
  • :w - Save the file.
  • :wq - Save and exit Vim.

I know many of you are far more experienced with Vim than I am, but I wanted to join the community and share with the world just how powerful this minimal tool truly is!
